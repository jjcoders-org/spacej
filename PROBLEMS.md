
# SpaceJ — Industry Problem Discovery

Status: Discovery
First product: Not selected

## Objective

Identify genuine problems in aerospace that can potentially become useful products, technologies, or engineering capabilities.

## Areas to investigate

### A. Mission analysis
- What makes mission design difficult?
- Are existing tools unnecessarily complicated for certain users?
- Which workflows involve excessive manual work?

### B. Satellite operations
- What makes satellite operations difficult?
- Are there repetitive manual processes?
- Which existing tools are insufficient?

### C. Telemetry
- How do teams inspect spacecraft data?
- What makes anomaly investigation difficult?
- Can useful improvements be validated with public or synthetic data?

### D. Ground systems
- What difficulties exist in ground-station coordination?
- Are scheduling and contact-planning workflows inefficient?

### E. Simulation
- Which spacecraft simulation capabilities are difficult to access?
- Where are existing engineering workflows fragmented?

### F. Space data
- What prevents organisations from efficiently using satellite data?
- Which processing or analysis workflows are expensive?

## Problem evaluation

Score each candidate from 1 to 5.

1. Problem severity.
2. Frequency.
3. Cost of current workaround.
4. Existing solution limitations.
5. User accessibility.
6. Technical feasibility.
7. Commercial opportunity.
8. Strategic relevance to SpaceJ.

Also document safety, legal, data-access, and liability concerns separately.

## Selection principle

We will not select a project because it sounds futuristic.

We select it when evidence shows that a specific user has a meaningful problem and we can build a useful solution.
